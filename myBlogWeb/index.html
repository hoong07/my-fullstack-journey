我的大学生活记录


一.平平无奇的开端

入学，怀揣着希望，跟着学校进度，开始c语言，靠着高中的英语水平，把四级过了，头脑一热，还报名了蓝桥杯，但是没有怎么准备，每天干得最多的还是打cs和pubg，最后成功cs玩到了一千多小时，pubg四百小时，但是心里其实还是挺担心学习和就业的，但是身上迟迟没有行动，只是偶尔01星球，阿伟他们的这些视频，有点丝毫强烈的危机感，但是没起什么很大的作用就是了。

二.学校第一次开专业讲座

这个时候老师也承认了ai对这个行业的冲击，并且鼓励考研，逃避接下来可能行业动荡的几年，我就开始思考到底要考研呢，还是直接就业。运气比较好，因为家里有很多人在从事互联网工作，或者也是在读it行业的哥哥姐姐，并且初中打篮球也认识了一个性格很好的叔叔，从他们身上了解到了很多这方便的知识
然而，在关乎最后的选择方面，他们并没有起什么决定性的作用，而是后来刷到一期关于是否考研的视频，很多人在聊家境，我也评论了，把家里情况都说了一下，其中一个评论说的真的摄人心魄：“你父母任何一方生个大病，你一分钱都掏不出来”，是的，很多人可能很残酷，他们可能会想：“优先过好自己的这一生”，但是可能因为我比较感性吧，我也不想赌那三年家里没有任何突发状况，这是我”第一次开智“
然后也是在这个时候我报名了蓝桥杯，第一次换幻想着“一鸣惊人”。

三.寒假躺平

其实我是一个有严重拖延症的人，脑子走在身体前面的人，我喜欢思考，喜欢计划，但是身体跟不上，就像古希腊的埃吉娅。这个病从小学一直延续到大学，我大脑明明清楚地告诉我：”你应该去做...“，但是身体它就不不动，所以我寒假本来计划着学cpp，刷算法题的，最终，也就学会了个"cin/cout"……没有电脑，我就玩手机，刷抖音。。。。。。

四.开学冲刺

我的拖延症只会在“大难临头”的时候才会被“治”好，在开赛前两周，我继续熟悉cpp的语法，学了点stl容器，前一周开始集中突破算法，也就会了个前缀和和二分，草草参加了比赛。

五.A组省二，“第二次开智”

这次运气很好，前缀和，二分都用上了，拿了个省二，然后这个时候我刷到了“一生的贵人”——千千，我羡慕他的认知，他虽然只是全栈开发，但是他了解很多其他方向的一些信息：比如上位机，运维，ai infra……我羡慕他的执行力：学习的时候每天都能肝六个小时，我还羡慕他自我认识的水平：他能清晰知道自己缺失的是什么，并且尽力去弥补，去补习……看了他很多的视频和直播，我也清晰地认识到：“我不能再废下去了”，于是我当时听从他的建议，开始前端开发的学习，并且结合提问gpt啊啥的各种ai，确定了接下来走TS + agent 全栈开发的路线，这个时候是六月初。

六.第一个暑假

在家确实不适合学习，会有很多诱惑。在这个暑假，虽然没有保持前期的自律能力，但是也按照最低限度完成了javascript的学习。也不后悔吧，只能说自律不是说完全不犯错，而是松懈之后可以回来不会后悔松懈，而是继续保持之前的节奏继续走下去。

七.开学Ajax，开始健身，还报名了驾校

然后开始Ajax的学习，开学一周左右拿下了。也开始注重体型，身材管理了，开始了健身之旅。还想着这个学期累点，想着一口气把一些事情全都做完，累是真的累，希望别一口气吃成胖子了。。。。。。

八.开始写个人博客网站，开始React的学习

学完Ajax就开始写个人博客了，也就是这个网站，然后开始React，网站大概花了一周时间。
然后这段时间学校课特别多，而且都是大物，离散，线代这些考核严格的课程，我也不是很想逃，因为后期考前还要拼死拼活地看网课，反正也就9周课，忍忍到后半学期就舒服了。

脑科学笔记


大脑严重

大概就是说每天大脑都处于一个低功耗的状态，但是大部分人的大脑正常来说就是两个状态：“工作”、“休息”，需要长思考，集中注意力的情况下，就是“工作”状态，而平常：休息，散步，吃饭都是“休息”状态，而我们经常刷抖音，焦虑，发呆，实际上都是让大脑处在一个低功耗的“工作状态”，这是很消耗心神的，所以你每天都很疲惫，尽管你到最后什么都没有吸收到，什么都没有学会······
然后后面学到的另一个东西就是关于生物节律清洗大脑的东西，大概就是说人在深度睡眠的时候，大脑会自动清洗老废杂质，具体理论不记得了。


大脑隐性疲劳

每天睡8小时但是依旧感觉很累，就是大脑一直处于隐性疲劳;方法论就是：固定生活节律

  1. 1.固定时间起床，并且接受5分钟左右阳光
  2. 2.低中强度有氧：散步、慢跑、骑车
  3. 3.降低决策密度：把决策用在重要的、需要深度思考的事情上面

放松前额叶

出去，在户外，0社交，不用手机，不想任何事情，就是集中在当下，感受户外，感受这条你没走过的路线，探索这条新路线。


关于记忆东西

比如记单词：看 + 写 + 读 == 三次记忆。因为大脑可以通过视觉，运动，听觉三种独立编码通道，来存储同一个信息，最后调用这个信息的时候通过任意一个通道来提取。

然后边走边背比坐着创造性思维提升60%，记忆保留率也提高40%


关于午睡

30～60分钟是最差的午睡时长，真正有效的睡眠长度是：20分钟和90分钟，并且这个时间是只包含真正在睡眠的时间。然后可以通过coffee nap，就是睡前一杯coffee，起效时间刚好是20分钟，所以醒来就是1+1>2

大学第一个思考


我第一次开始这个思考，是大一下学期的时候：

当时是大物期中考试，由于大一上我基本没咋学习，就是游戏 + 上课想听就听，不想听就不听，优秀率100%，并且当时我以为出自湖南，高考也算是失误才来到这个学校，自认为智商和能力高于大部分外省份的，所以很理所当然。然而那一次期中考试，我身边的人基本上都是90+，而我只有79。

我开始愧疚我平常上课没有好好听，我在后悔提前交卷没检查，但是想着想着，我突然意识到高数大物这些通识课似乎对就业没什么帮助，然后开始刷抖音，再到知乎，再到牛客，发现很多手中有不错offer的人，很早就开始技术栈的学习了，而不是把大把时间花在这些理论课上，甚至很多大牛经常是旷课去学习一些技术，因为知道学校的课，不管是专业课还是水课，其实都很水。

似乎害怕绩点落后，排名落后，成绩不好这些都是高中那种学生思维带来的荼毒，然后我也决心开始自主学习技术栈，从前端开始，目标是全栈工程师，于是我就开始了自学之旅。

当然喽，大学也是一个资源丰富的地方，就拿我们学校来说，就有很多学生成立的项目，甚至在准备开公司，各种老师也有很多科研项目，也有很多放松心情，财经类，法律类的课程，你可以学习。这些资源都是可以利用的，所以也不是极端地去拒绝学校，去远离学校的课程，而是挑选真正对你有帮助的课程去学习，水课就逃，没用的课就逃，与其受那一个半小时的煎熬，还不如去健身，甚至说‘耍起’。
